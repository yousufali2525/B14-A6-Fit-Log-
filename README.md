
#  FitLog

FitLog is a modern fitness workout tracking web application where users can explore workouts, save their favorite exercises, create a personal workout plan, and track important workout information such as duration, calories, and rating.

##  Project Description

*FitLog* is designed to make workout planning simple and organized.

Users can browse different exercises, view workout information, save exercises for later, and manage their personal workout plan. The application provides a clean and responsive interface that works across desktop, tablet, and mobile devices.

##  Key Features

### 1.  Workout Library

Users can browse a collection of different workouts and exercises.

Each workout provides useful information such as:

- Exercise name
- Category
- Duration
- Calories burned
- Rating
- Exercise image

---

### 2.  Save for Later

Users can save workouts that they want to do later.

Saved workouts can be:

- Viewed from the Saved section
- Removed from the saved list
- Sorted by duration
- Sorted by calories
- Sorted by rating

---

### 3.  Personal Workout Plan

Users can create and manage their own workout plan.

The plan shows:

- Total exercises
- Total workout minutes
- Total calories
- Selected exercises

Users can also remove exercises from their plan whenever they want.

---

### 4.  Sort Workout Data

FitLog includes a sorting system that allows users to organize saved workouts by:

- *Duration*
- *Calories*
- *Rating*

The workout list updates dynamically when the user changes the sorting option.

---

### 5.  Responsive Design

FitLog is fully responsive and designed to work on:

-  Mobile devices
-  Tablets
-  Laptops
-  Desktop screens
